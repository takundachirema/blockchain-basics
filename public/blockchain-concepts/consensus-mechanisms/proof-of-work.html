Proof of Work (PoW)

How PoW Works

In Proof of Work, miners compete to solve a computational puzzle by repeatedly hashing block data with different nonce values. The first miner who finds a valid hash below the target broadcasts the new block.

  • Mining power is measured by hash rate.
  • Difficulty adjusts so block production stays near a target rate.
  • Other nodes verify the block quickly.

How the Zero Target Adjusts with Mining Power

The network aims for a stable average block time. If total mining power rises, blocks would be found too quickly, so the protocol increases difficulty (effectively requiring a rarer hash pattern). If mining power drops, difficulty is reduced so blocks do not slow down too much.

In Bitcoin, this retargeting happens periodically (about every 2016 blocks, roughly two weeks) based on how fast the previous period was mined.

Block Rewards in PoW

Honest miners are paid through:

  • Block subsidy: Newly minted coins.
  • Transaction fees: Fees from included transactions.

These rewards create direct incentives to follow consensus rules and publish valid blocks accepted by the network.

Cost of Being Dishonest in PoW

  • High upfront cost: Attackers need massive hash power (hardware + electricity).
  • Opportunity cost: While attacking, miners may lose normal block reward revenue.
  • Attack uncertainty: If the network rejects the attack chain, the attacker pays real costs with little or no return.
  • Asset impact: Successful attacks can damage market trust and lower the value of the attacker’s own holdings.
Security intuition: PoW protects the chain by making attacks economically and physically expensive.
